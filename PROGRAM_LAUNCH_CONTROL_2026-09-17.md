# FinanceMeta Program Launch Control — 2026-09-17

Goal: launch programs that create a pipeline from education -> research -> publication/building without duplicating Bu1LD.

## Launch 1 — Quant Research Fellowship

Duration: 6–8 weeks.
Tracks: factor research; macroeconomics; market microstructure; behavioral finance; ML for finance; portfolio/risk methods.
Required standards: leakage checks, frozen splits, regime tests, transaction-cost assumptions, benchmark parity, failure preservation, and reproducible notebooks/scripts.
Final artifact: research memo/paper + code + evidence package.

## Launch 2 — FinTech Studio

Duration: 4–6 weeks.
Teams build one useful financial tool such as a portfolio analysis tool, market dashboard, simulator, risk visualizer, or financial education application.
Required deliverable: working public/demo artifact, testable user problem, instrumentation, and concise technical/product memo.

## Launch 3 — Investment Research Competition

Teams receive or select a public company/sector under one common rubric.
Required submission: thesis, valuation framework, catalysts, risks, scenario analysis, source ledger, and presentation.
No fabricated proprietary data or unsupported certainty.

## Publishing engine — FinanceDebriefed

Weekly issue structure:
1. one macro event
2. one market move
3. one company/sector
4. one data chart
5. one plain-language explanation
6. one 'what would falsify this interpretation' note

## Partner offer

Small default asks:
- provide one speaker/mentor/judge
- distribute applications
- co-host one workshop or case session
- provide a bounded public dataset/problem
- cross-promote the final showcase

## Launch definition of done

Program brief, application form/questions, fixed timeline, selection rubric, mentor/judge brief, participant deliverables, research/integrity standards, final showcase format, and one accountable operator must all exist before public launch.

## Morning target

Quant Research Fellowship should be launch-ready; FinTech Studio should have a complete operating brief; Investment Research Competition should have a common rubric and submission template; FinanceDebriefed should have its first four issue briefs scoped.
