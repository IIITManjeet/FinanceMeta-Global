# interpreter matches, this file hashes to the digest recorded in the contract,
# AND every distribution actually importable in the environment matches the pins
# below. The first two alone are not a lock: they do not look at site-packages.
#
# Install, in this order:
#   python -m pip install --require-hashes -r microstructure-sim/requirements.lock.txt
#   python -m pip install -e microstructure-sim --no-deps --no-build-isolation
#
# --no-build-isolation is required, not optional. Without it pip fetches the build
# backend fresh and unhashed on every install, outside this lock entirely.
# pyproject.toml declares exactly the setuptools and wheel versions pinned here,
# so the isolated and non-isolated paths cannot disagree.
#
# Wheels only, by design. An sdist hash would let --require-hashes validate a
# source build on any platform whose wheel is absent, which is the opposite of a
# lock. A platform not listed below fails cleanly instead of degrading silently.
#

# macOS arm64 and x86_64, win_amd64, plus pure-python wheels.
